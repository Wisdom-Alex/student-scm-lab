# Student Score Manager

A small modular Python project used for SEN 401 (Software Configuration Management and Maintenance).

## Project structure

| Path | Purpose |
|------|---------|
| `app.py` | Main script that runs the demo application |
| `students.py` | Data module holding the list of students (name, score) |
| `utils/helpers.py` | Helper functions: highest score, lowest score |
| `requirements.txt` | Dependency list |

## Usage

```bash
python app.py
```
